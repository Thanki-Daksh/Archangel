<h3><strong>The Role:</strong></h3>
<p>&nbsp;</p>
<p>We are looking for a Senior Fullstack Python Developer to join our fast-growing Network.</p>
<p>In this role, you’ll lead the design and implementation of scalable backend services and APIs using Python (FastAPI, Django, or Flask), while delivering polished, performant user interfaces using modern frontend frameworks such as React.js or Vue.js.</p>
<p>&nbsp;</p>
<h4><strong>What we are looking for:</strong></h4>
<ul>
<li>5+ years of professional software development experience with strong fullstack exposure.</li>
<li>3+ years of production experience with Python (FastAPI, Django, Flask).</li>
<li>Solid knowledge of JavaScript/TypeScript, HTML5, CSS3.</li>
<li>Strong experience with React.js or Vue.js (or similar modern frameworks such as Next.js/Nuxt.js).</li>
<li>Experience with relational databases (PostgreSQL, MySQL) and ORMs such as SQLAlchemy or Django ORM.</li>
<li>Strong understanding of RESTful API design and integration patterns.</li>
<li>Experience writing automated tests (unit, integration) for both backend and frontend.</li>
<li>Practical experience with Docker and familiarity with CI/CD pipelines (GitHub Actions, GitLab CI, CircleCI, etc.).</li>
<li>Experience deploying and operating services in the cloud (AWS, Azure, GCP).</li>
<li>Strong problem-solving skills and excellent English communication (written and spoken).</li>
<li>Ability to work independently and deliver high-quality results in a remote setup.</li>
<li>Located in CET timezone (+/- 3 hours), we are unable to consider applications from candidates in other time zones.</li>
</ul>
<p>&nbsp;</p>
<h4><strong>Nice-to-have:</strong></h4>
<ul>
<li>Deep experience with TypeScript and modern frontend tooling (Vite, Webpack, Turbopack).</li>
<li>Familiarity with microservices, DDD, CQRS, or event-driven architectures.</li>
<li>Experience with GraphQL and schema design.</li>
<li>Knowledge of message brokers (RabbitMQ, Kafka, Redis Streams).</li>
<li>Experience with Kubernetes or other orchestration platforms.</li>
<li>Exposure to performance tuning, caching strategies, and observability (logs, tracing, metrics).</li>
<li>Security best practices (OWASP, auth flows, OAuth2/OpenID Connect).</li>
<li>Background in startups or fast-paced product environments.</li>
<li>Contributions to open-source projects or published technical content.</li>
</ul>
<p>&nbsp;</p>
<h4><strong>Responsibilities:</strong></h4>
<ul>
<li>Design, implement, and operate scalable backend services using Python (FastAPI, Django, Flask).</li>
<li>Build and maintain responsive, accessible web UIs using React.js, Vue.js, or similar modern frameworks.</li>
<li>Design, document, and consume RESTful APIs (and optionally GraphQL).</li>
<li>Integrate backend systems with relational and NoSQL databases.</li>
<li>Ensure high code quality through unit/integration tests, code reviews, and automated pipelines.</li>
<li>Make architectural decisions across backend, frontend, and system integration (monolith vs microservices).</li>
<li>Collaborate with designers and product teams to translate requirements into technical solutions and excellent user experiences.</li>
<li>Troubleshoot production issues, optimize performance, and ensure reliability and security.</li>
<li>Mentor and guide other engineers, helping elevate team best practices.</li>
<li>Work in an agile environment and contribute to continuous process and delivery improvements.</li>
<li>Document architectural decisions, API contracts, workflows, and deployment procedures.</li>
</ul>
