> ESM: Intermediate Web Applications Developer - JAVA/AWS (Remote)

<img src="https://we-work-remotely.imgix.net/logos/0171/5966/logo.gif?ixlib=rails-4.0.0&w=50&h=50&dpr=2&fit=fill&auto=compress" />

<p>
  <strong>Headquarters:</strong> Vienna, Virginia, 22180 United States
    <br /><strong>URL:</strong> <a href="http://esmcorp.net">http://esmcorp.net</a>
</p>

<p>Enterprise Solutions and Management (ESM) is a rapidly growing government contractor that provides strategic IT services that meet mission needs for Defense and Federal customers. We are hiring an <strong>Applications Developer</strong> for an exciting <strong>remote</strong> opportunity.</p>
<p><strong>Job Description and Responsibilities</strong></p>
<p>The Intermediate Web Application Developer will support a federal cloud migration effort involving the transition and follow on sustainment of virtual servers and related applications to a cloud-based environment such as Amazon Web Services (AWS). The Developer will provide application development and technical support across web applications, cloud-hosted environments, database integrations, APIs, and related systems.</p>
<p>The candidate should have foundational knowledge of web application development, cloud concepts, and application/database integration, with the ability to adapt to the specific platform and tools ultimately selected for the migration effort.</p>
<p><strong>Required Knowledge, Skills and Abilities (KSA)</strong></p>
<p>The Intermediate Web Application Developer will be responsible for supporting application development, enhancement, integration, and migration activities in a cloud environment. Responsibilities may include:</p>
<ul>
<li>Knowledge of AWS services and cloud-based application hosting concepts, including application deployment, migration, monitoring, storage, networking, and security considerations.</li>
<li>Knowledge of Java and Python used to develop, maintain, enhance, test, and support web-based applications.</li>
<li>Knowledge of SQL and PL/SQL concepts used to support relational database integration, application functionality, and data access.</li>
<li>Knowledge of application programming interfaces, including concepts for developing, consuming, integrating, and troubleshooting APIs.</li>
<li>Knowledge of web application development concepts, practices, and frameworks used to support enterprise or mission-focused applications.</li>
</ul>
<p><strong>Desired KSA</strong></p>
<ul>
<li>Experience supporting federal government customers or federal IT environments.</li>
<li>Experience working in Linux-based application environments.</li>
<li>Experience with Appian or other low-code/cloud-supported application development platforms.</li>
<li>Familiarity with federal cloud security, compliance, and operational requirements.</li>
<li>Experience supporting virtual server migration, application refactoring, or federal cloud modernization efforts.</li>
</ul>
<p><strong>Minimum Training, Education, and Certifications</strong></p>
<ul>
<li>Bachelor's degree in a relevant field</li>
<li>Three to Five (3-5) years experience</li>
<li>Specific Experience with:<ul>
<li>Java</li>
<li>Python</li>
<li>AWS</li>
<li>SQL, PL/SQL</li>
<li>API integration</li>
</ul></li>
</ul>
<p><strong>Minimum Clearance</strong></p>
<ul>
<li>This position requires the ability to obtain and maintain a Public Trust suitability determination.</li>
<li>An existing or prior Public Trust, Secret, or higher-level DoD clearance is preferred and may support a more efficient onboarding process. Candidates should clearly identify any active or prior Public Trust suitability determination or DoD clearance during the recruiting process.</li>
</ul>
<p><strong>Physical Requirements</strong></p>
<ul>
<li>This position is 100% remote and primarily involves computer-based work in a home office or other remote work environment.</li>
<li>The candidate must be able to remain in a stationary position for extended periods while using a computer and other standard office equipment. The role requires the ability to communicate effectively by phone, video conference, email, and other electronic collaboration tools.</li>
<li>The candidate must be able to use a keyboard, mouse, monitor, and related computer equipment to perform application development, documentation, troubleshooting, and collaboration activities. Specific vision abilities required include the ability to read information on a computer screen and review technical documentation.</li>
<li>Reasonable accommodation may be made to enable individuals with disabilities to perform the essential functions of the position.</li>
</ul>

</ul>
